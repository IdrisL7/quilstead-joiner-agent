Access to systems is requested from the role access matrix, never from an individual request in email or Slack. Each request is approved in the identity provider by the approver named in the matrix: IT for core tools, the manager for team tools, and Finance for finance systems.

Elevated access is never granted before the start date and always requires the named approver. Nobody, including automation, can grant access directly; automation may only file requests.

Access requests are filed at least two working days before the start date so that accounts are ready on the first morning. Requests that are not approved by the start date are escalated to IT.
